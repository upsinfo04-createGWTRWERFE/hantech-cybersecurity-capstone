HanTech Cybersecurity Capstone Project

Project Overview

This repository documents my work on the TS Academy Cybersecurity Capstone Project, titled “From Vulnerability to Compliance: Securing Legacy and Cloud Systems at HanTech.”

The project focuses on identifying security weaknesses, assessing risks, recommending security controls, and understanding governance, risk and compliance (GRC) practices.

Practical Lab Environment

* Attacker machine: Kali Linux
* Target machine: Metasploitable 2
* Virtualisation platform: Oracle VirtualBox
* Scanning tool: Nmap

All practical testing is conducted within an isolated virtual lab environment.
